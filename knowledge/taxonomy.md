# 新皮肤演示评论标注规则 第一版

## 先判断讨论对象

只有针对目标新皮肤或套装的评论进入三类评价统计。只谈博主、视频剪辑或其他皮肤的评论排除。回复缺少父评论时，不补造讨论对象；对象不明的评论交人工复核。

## 评价倾向 三分法

| 标签 | 判定标准 |
| --- | --- |
| 积极 | 对目标皮肤明确表达喜欢、认可或值得买等正面评价 |
| 消极 | 对目标皮肤明确表达不喜欢、失望、不值或不买等负面评价 |
| 中立 | 针对目标皮肤，但没有明确好评或差评；纯提问、事实陈述，以及正负兼有且无明显整体方向的评论 |

必须结合完整评论判断，不依靠情绪词表或单个表情。自述“已买”不自动算积极。正负兼有的评论归中立时，保留原文中的两面评价供原因分析参考。无法读懂的反讽或梗不应臆测；记录人工复核原因。

## 积极与消极的原因

从原评论实际表达中提取，不根据评价标签猜原因。第一版原因标签：外观设计、枪声音效、击杀与终结特效、主观手感、价格与价值、与已有皮肤重复、其他明确原因。一条评论可有多个原因，并保留对应原句。

## 皮肤本身的改进诉求

仅记录评论明确希望皮肤改变的细节，如配色、模型、枪声、特效或动画。单纯“不喜欢”但没有具体方向，不改写成改进建议。对博主、视频剪辑、录音或展示角度的建议排除。

## 标注字段

`video_id`、评论原文、是否讨论目标皮肤、评价倾向、原因及原句、皮肤改进诉求及原句、是否需人工复核。每条目标皮肤相关评论只给一个评价倾向标签。
